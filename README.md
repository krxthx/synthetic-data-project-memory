# Contoso Synthetic Project Memory Dataset

A dense synthetic organizational dataset for testing long-term project memory.

## Scope
- Organization: Contoso (fictional)
- Timeline: 2026-01-05 to 2026-06-19
- Total records: 2000
- Total named people: 84
- No source code or codebase activity is included.

## Projects
- ATLAS: Atlas Customer Onboarding | 420 records | 19 project/shared members
- PULSE: Pulse Store Operations Intelligence | 360 records | 17 project/shared members
- NOVA: Nova Sales Opportunity Intelligence | 400 records | 18 project/shared members
- HARBOR: Harbor Identity Modernization | 480 records | 20 project/shared members
- ORBIT: Orbit Financial Planning | 340 records | 18 project/shared members

## Sources
- Teams messages
- Outlook email threads
- Calendar recording transcripts
- SharePoint business announcements, status reports, steering decisions and client updates
- OneDrive implementation specs, working notes, test plans and process maps
- Confluence architecture decisions, implementation decisions, anti-patterns and dependency notes

## People model
Projects include executive/business sponsors, program/project management, product, BAs, architects, engineers, QA, change management, client roles and SMEs. People records include expertise, responsibilities and what each person has built.

## Memory challenges
Current and superseded decisions, cross-project dependencies, SME ownership, business rationale, client feedback, risks, architecture decisions, anti-patterns, point-in-time status reports, corrections, provenance trails, and conflicting historical context.
