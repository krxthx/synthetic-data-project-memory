# Meridian Group Organization Memory

This directory contains enterprise-level material that applies across Meridian Group rather than to a single transformation project.

## Contents

- `policy_catalog.json`: structured policy metadata, authority, ownership, review dates and key controls.
- `policy_register.csv`: compact governance register for all current policies.
- `records.jsonl`: normalized organization-wide announcements, implementation guidance and clarifications.
- `policies/hr/`: people, workplace flexibility, leave, accommodation, performance and mobility policies.
- `policies/it/`: acceptable use, endpoints, identity, access, data handling, retention and generative-AI policies.
- `policies/admin/`: procurement, vendors, travel, expense, workplace access and continuity policies.

Policy documents are authoritative when their status is `Current`. Organization records capture how those policies were communicated and clarified over time. A later message does not override policy text unless it identifies an approved amendment or successor policy.
